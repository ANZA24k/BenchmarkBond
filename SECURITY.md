# Security and trust boundaries

- **Immutable rules.** No protocol-update method; deployment fixes canonical terms and their SHA-256. Every revision's manifest is immutable. `used_manifests` prevents cross-submission replay, and one evaluation per revision prevents duplicate decisions.
- **Source allowlist.** HTTPS `raw.githubusercontent.com` with literal 40-character lowercase hexadecimal commit IDs; no userinfo, port, query, fragment, redirects in the submitted URL, encoded characters, traversal or branch references. A source URL is a locator, **not** proof of source authorship; GitHub availability and serving behavior are external trust dependencies.
- **Byte authentication.** Validate exact declared length and SHA-256 **before decoding**. Invalid UTF-8 is permanently invalid, not a transient retrieval error. Mismatches return `INVALID`. Missing/non-200 sources return `INCONCLUSIVE`; HTTP 429/5xx causes a retryable transaction failure, preserving state. Transport exceptions abort evaluation.
- **Resource limits.** At most three sources, 8192 declared bytes per source, 16384 aggregate, 1-4 named metrics, 3-40 paired trials, 1000 submissions and three revisions. The GenVM HTTP subsystem must enforce its own response-size protections; a declared-size limit by itself does not prevent downloading an unexpectedly huge resource before the length check.
- **Prompt injection.** Untrusted evidence is JSON-delimited and explicitly labeled data. Deterministic schema, trial count, duplicate IDs, and metric arithmetic cannot be overridden by a model. Model excerpts must be literal source substrings; validators re-fetch before evaluating or accepting excerpts. Prompt injection can still influence judgment; consensus limits single-model discretion, not model-level systemic risks.
- **Consensus.** Custom `gl.vm.run_nondet_unsafe` validators independently repeat web retrieval, byte authentication, metric reconciliation, and semantic classification; matching labels and fingerprints required. A schema-only check is **not** treated as consensus. LLM disagreements fail to settle and require retrial.
- **Non-custodial.** No payable method, escrow, transfer, locked bond, refund, or payout; no possible double settlement or stuck user funds. The contract is not designed to accept GEN and cannot promise recovery of funds accidentally transferred outside its declared methods.
- **Limitations.** Matching hashes authenticate content bytes but not its scientific authenticity. Self-reported paired observations can be fraudulent. Validators cannot establish undisclosed training contamination or hardware changes without stronger independent sources. A highly consistent false report may still be accepted. Capped revisions and immutable verdicts limit recovery options; append a fresh submission if the cap is exhausted.

Responsible reports: open a GitHub issue without exploits, secrets, or sensitive tokens; provide a minimal private reproduction to the maintainer for sensitive findings.
